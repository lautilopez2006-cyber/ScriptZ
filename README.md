# ScriptZ

**Estudio de escritura de guiones gratuito**: cine, series, teatro, radio, cómic y guion audiovisual. Funciona sin conexión en Windows, macOS, Linux, teléfonos y tabletas.

- Sitio y descargas: https://lautilopez2006-cyber.github.io/ScriptZ/
- Usar en el navegador o instalar en el teléfono: https://lautilopez2006-cyber.github.io/ScriptZ/app/
- Todas las versiones: [Releases](../../releases)

Este repositorio contiene el sitio web, la versión para navegador y los instaladores publicados.

## Instalar

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `ScriptZ_x.y.z_x64-setup.exe` (o la Microsoft Store, próximamente) |
| macOS 11+ | `ScriptZ_x.y.z_universal.dmg` |
| Linux | `.AppImage`, `.deb` o `.rpm` |
| Teléfono / tableta | Abrí la versión del navegador y elegí "Instalar app" (Android) o "Agregar a inicio" (iPhone/iPad) |

**Aviso de Windows:** el instalador directo todavía no tiene una firma de pago, así que Windows puede mostrar "Windows protegió su PC". Tocá **Más información → Ejecutar de todas formas**. La versión de la Microsoft Store no muestra ese aviso.
