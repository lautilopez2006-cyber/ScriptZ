# Formatos

| Formato | Importa | Exporta | Notas |
|---|:-:|:-:|---|
| ScriptlZ (.scriptz) | ✓ | ✓ | JSON legible. Conserva todo: historia, producción, revisiones y comentarios |
| Final Draft (.fdx) | ✓ | ✓ | Elementos, diálogo dual, negrita/cursiva/subrayado, números de escena, portada, resúmenes y revisiones |
| Fountain | ✓ | ✓ | Énfasis, diálogo dual, notas, secciones y portada |
| Word (.docx) | ✓ | ✓ | *Flujo*: estilos de Word editables. *Exacto*: misma paginación que el PDF |
| PDF | ✓ | ✓ | Importa guiones con texto seleccionable y reconoce los elementos por la sangría. Exporta con fuentes incrustadas, marca de agua y marcadores |
| Fade In (.fadein) | ✓ | — | Lee el XML interno (Open Screenplay Format) |
| Celtx | ✓ | — | Proyectos `.celtx` con guion HTML |
| Highland / WriterDuet | ✓ | — | Paquetes con Fountain interno |
| HTML / EPUB / Markdown / Texto | — | ✓ | HTML paginado para leer o publicar; texto monoespaciado con las páginas exactas |

## Medidas
- **Carta:** 55 líneas por página.
- **A4:** 60 líneas por página.
- Tipografía Courier de 12 pt, con Liberation Mono (métricas idénticas).
- Márgenes estándar de industria. Se pueden ajustar por elemento en **Formato del documento → Estilos**.
